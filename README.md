Valley Courier is a bush-plane courier game in one long procedurally built valley: chase and cockpit views over recognisable terrain, a lit instrument panel, three sorties (ring run, parcel drops, landing tour), fuel and damage that turn each flight into decisions, and procedural engine and wind sound. No build step, no network: static files under game/ that any static server can serve.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Fly with the arrow keys (pitch and bank), A/D to bank, W/S for throttle, hold the mouse to steer, C for the cockpit view, Space to drop a parcel, G for the gear, P to pause, R to restart.
